Featured project

AI-Assisted Anomaly Detection for E-commerce Orders

Designed & delivered

Python | Scikit-learn | Plotly | Mattermost | SRE

A versioned hourly-order analysis system that identifies unusual country-level behavior using statistical rules and an unsupervised ML ensemble. The current V4 workflow automatically selects new input, classifies severity, and produces operator-ready CLI, HTML, and Mattermost output.

Key capabilities

  • Isolation Forest, Local Outlier Factor, and One-Class SVM ensemble
  • Mean, standard deviation, latest-order, and Z-score context by country
  • Critical, High, Medium, and Low operational severity classification
  • Latest-file automation, configurable thresholds, and complete results
  • CLI tables, interactive HTML reports, and Mattermost notifications
  • Investigation and support-ticket workflow backed by an analysis playbook

Cloud Portfolio Platform
