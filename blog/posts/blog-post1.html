Optimizing Cloud Infrastructure with Terraform

Derived from AVASOFT (Nov 2022 - Oct 2024)

At AVASOFT, I standardized AWS and Azure provisioning using Terraform modules and remote state. We integrated GitLab CI/CD to validate plans, run security checks, and gate applies with approvals. The result was faster, safer changes and more consistent environments.

  • Reusable modules for VPC, AKS/EKS, IAM, and serverless components.
  • GitLab pipelines with fmt, validate, plan, and OPA policy checks.
  • Automated tagging, cost-center labels, and drift detection.
